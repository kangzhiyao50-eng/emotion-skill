# 极简像素情绪海报生成器

## 适用任务
生成 3:4 比例的极简像素风情绪海报，用于社交媒体分享或个人打卡。

## 输入要求
1. emotion_en: 情绪英文单词（如 HAPPY）
2. emotion_cn: 中文短句（如“把开心存好”）
3. face_png: 中心像素表情图片
4. bg_color: 背景色（如 #FFD700）

## 执行步骤
1. 创建一个宽高比 3:4 的容器，背景色设为 bg_color。使用相对定位（`position: relative;`），并预留四周内边距（如 `padding: 40px;`）。
2. **左上角文字区**：第一行放置 emotion_en，必须使用 'Press Start 2P' 像素字体，字号设为 32px（或 2rem），加粗显示，黑色。（其余规则全部保持不变**必须使用 'Press Start 2P' 像素字体**，字号大，黑色。
   - 第二行放置 emotion_cn，使用宋体，浅灰色，字号较小，放在英文正下方。
3. **中心表情**：将 face_png 放在画面绝对正中心（`position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%);`）。
4. **表情尺寸限制（关键）**：将 face_png 的宽度放大到容器的 **65%**，但必须加上最大高度限制（`max-height: 55%;`），确保它是一张巨大的海报脸，但**绝对不能和左上角的文字重叠，也绝对不能冲出画布边缘**。
5. **底部日期**：在容器最底部居中放置当前日期，浅灰色小字。

## 合格标准
- 英文和中文紧紧贴着画面的**左上角**。
- 情绪表情占据画面的绝对主体（非常大），且完美居中。
- 表情、文字、边缘之间互不重叠。
- 英文字体是像素风。
02

背景与需求

制作这种生成海报的 Skill，是突然想以情绪的方向拓展（正好也映射现在人们对情绪的处理态度）。但每个人展现情绪的形式是不同的，所以想固定某一种风格：像素风 + 高饱和颜色。

以往在网页设计里，需要手动去改颜色、表情、文字；现在直接在 Skill 里改想要的颜色、字体，加上自己的表情，就能直接输出海报，不必在网页端一个一个挑选。这款 Skill 适合想要批量生成不同情绪海报来分享的用户。

03

文件与流程

SKILL.md 只规定四个变量：情绪英文 emotion_en、中文短句 emotion_cn、中心表情图 face_png、背景色 bg_color。

人负责提出意图，Agent 负责按这套 SKILL.md 输出代码；规则一旦写定，就变成可以反复调用的模板。

  1. 画布比例固定为 3:4，画布颜色由用户按自己想要的颜色自行搭配。
  2. 情绪表情占据画布一半以上，作为绝对主体，位于画布中下部，并与整张海报统一为像素风格。表情可由用户自己挑选上传（可用图片），也可以在网页端制作后保存使用。
  3. 英文字体统一为像素风（也可以直接修改 SKILL.md 里的英文字体），位于画布左上角，尺寸偏大；其中文解释都是情绪关键词。
  4. 中文字体固定在英文字体下方，浅灰色、字号偏小，不抢夺主体视觉；内容针对该情绪，是一句随机的激励话语。
  5. 日期放在画面最底部的中间位置，通常为当天日期。

合格标准：字体与表情统一像素风；画面内容比例不超出画布大小；文字与表情之间互不重叠。

04

关键修改

V1 阶段：初版生成

问题整个画面布局太小，没有铺满画布，字体也不符合像素风格要求，每一块都很散。

SKILL.md 修改 
把原来的：
“画面正中心放置 face_png，宽度占 60%……”

改成：
“画面正中心放置 face_png，宽度占 80%（或者 85%），限制最大高度不超过容器的 55%，确保表情占据视觉主体，且不能超出边界。”

V2 阶段：元素重叠

问题文字与情绪表情重叠，英文字体也未修改成像素风格。

SKILL.md 修改 
## 执行步骤
1. 创建一个宽高比 3:4 的容器，背景色设为 bg_color，使用 Flex 布局垂直居中（`display: flex; flex-direction: column; align-items: center;`）。
2. **顶部标题**：在最上方放置 emotion_en，**必须使用 Google Fonts 引入的像素字体（如 'Press Start 2P', monospace）**，字号大，黑色，加粗。如果字母过长，强制换行。
3. **副标题**：在英文正下方（间距 20px），放置 emotion_cn，使用宋体（SimSun），浅灰色，字号较小。
4. **中心表情**：在中文下方，放置 face_png，宽度占容器的 60%（或 70%），使用 `image-rendering: pixelated;` 确保边缘锐利。
5. **底部日期**：在容器最底部，放置当前日期，浅灰色小字。

## 合格标准
- 所有元素垂直排列，**绝对不能发生重叠**。
- 英文字体必须是像素方块风格。
- 元素不超出边界。
- 整体风格极简、克制。

05

两次测试

事先不断修改黄色大笑海报，最终总结出一份 SKILL.md 的最终模板。但因为还不能确定这份规则是否真能稳定达到效果，于是又增加了一份情绪海报的生成：只改变变量——把 HAPPY 改成 ANGRY，背景色从 #FFD700 换成 #FF6B6B，并换上一张生气情绪的像素表情图，进行第二轮测试。

测试结果如下：

  1. Agent 能够稳定按照 SKILL.md 的规则，完整实现左上文字 + 下方中文解释 + 主体情绪表情 + 底部日期，并满足像素风格。
  2. 规则中限制了距离，主体情绪表情与上方、下方文字保持安全距离，没有出现重叠或溢出的问题。
  3. 每张情绪海报的最终效果统一，位置、比例、大小、字体都相同。

但也存在一定局限：情绪表情仍需自己去找图片，或在网页端自行生成；遇到较长的情绪英文单词时可能处理得不够好，需要手动调试。

06

个人收获

通过制作、修改、完善 SKILL.md 规则的过程，我发现它对“靠左来一点”“画面比例不要太大”这类模糊描述其实并不敏感——它听不懂“一点”是多少，也不知道“不要太大”对应什么数值。真正有效的是更准确、可执行的提示词：把“靠左来一点”换成“top: 40px; left: 40px”，把“比例不要太大”换成“width: 65%; max-height: 55%”，它在修改海报时就会明显更准、更容易一次到位。

也许对于 Agent 来说，海报算是一个相对简单的任务：只要规则写清楚，版式、字体、间距都能稳定复现、一次性完成。真正可以继续延伸的是质感——增加某种纹理，或者做成邮票效果、钥匙扣的感觉，让同一套规则产出更多形态的小物。
