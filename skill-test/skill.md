# 极简像素情绪海报生成器

## 适用任务
生成 3:4 比例的极简像素风情绪海报，用于社交媒体分享或个人打卡。

## 输入要求
1. emotion_en: 情绪英文单词（如 HAPPY）
2. emotion_cn: 中文短句（如“把开心存好”）
3. face_png: 中心像素表情图片
4. bg_color: 背景色（如 #FFD700）

## 执行步骤
1. 创建一个宽高比 3:4 的容器，背景色设为 bg_color。使用相对定位（`position: relative;`），并预留四周内边距（如 `padding: 40px;`）。
2. **左上角文字区**：第一行放置 emotion_en，必须使用 'Press Start 2P' 像素字体，字号设为 32px（或 2rem），加粗显示，黑色。（其余规则全部保持不变**必须使用 'Press Start 2P' 像素字体**，字号大，黑色。
   - 第二行放置 emotion_cn，使用宋体，浅灰色，字号较小，放在英文正下方。
3. **中心表情**：将 face_png 放在画面绝对正中心（`position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%);`）。
4. **表情尺寸限制（关键）**：将 face_png 的宽度放大到容器的 **65%**，但必须加上最大高度限制（`max-height: 55%;`），确保它是一张巨大的海报脸，但**绝对不能和左上角的文字重叠，也绝对不能冲出画布边缘**。
5. **底部日期**：在容器最底部居中放置当前日期，浅灰色小字。

## 合格标准
- 英文和中文紧紧贴着画面的**左上角**。
- 情绪表情占据画面的绝对主体（非常大），且完美居中。
- 表情、文字、边缘之间互不重叠。
- 英文字体是像素风。
